# Changelog

## Unreleased — Phase 1 foundation

- Added the React, TanStack Start, TanStack Router, and strict TypeScript app foundation.
- Added Tailwind CSS 4 dark-theme tokens and shadcn/ui configuration conventions.
- Added Zod server/public environment parsing and a non-secret `.env.example`.
- Added PostgreSQL, Drizzle ORM, migration configuration, and a connection check.
- Added a local PostgreSQL Docker Compose service with persistent storage and health check.
- Added a Node.js fetch-handler runtime command for local production-build checks.
- Added ESLint, Prettier, Vitest, scripts, and implementation-status documentation.
- Replaced the foundation heading with the supplied official AURYTH logo image,
  displayed responsively without altering its artwork.

No authentication, storefront, commerce schema, checkout, Razorpay, Shiprocket,
Oracle, email, or production deployment functionality is included.
